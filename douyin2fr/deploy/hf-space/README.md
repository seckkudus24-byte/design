# Douyin → France AI

Supprime les sous-titres chinois incrustés dans des vidéos courtes (≤ 5 min) et reconstruit
l'arrière-plan (OCR PP-OCR + inpainting vidéo par flux optique + LaMa). Accès protégé par jeton.

À utiliser uniquement sur des vidéos que vous avez le droit de réutiliser.
